# 设计对照：原全问卷设计 vs 建议混合设计

> 本案例为"设计阶段诊断"，此处对照的不是已发表结论，而是**研究设计本身**在替代前后的差异。

## 1. 逐构念测法对照

| 构念 | 原设计（全问卷） | 建议混合设计 | SRG | 主要收益 |
|---|---|---|---|---|
| GCS | 感知题（3 维） | 产品图像/文本客观编码，或实验操纵；感知题作操作检查 | A（可 S） | 增强因果识别，减少自报 |
| CI | 问卷（3 维） | 问卷为主 ＋ 国潮话语 UGC 三角 | C | 保留效度，增加外部证据 |
| SBC | 问卷（3 维） | 问卷为主 ＋ 身份 UGC × 忠诚行为三角 | C | 同上 |
| PV | 问卷（2 维） | 价格/参数客观化 ＋ 质量感知问卷 | B | 客观维度去自报 |
| BA | 问卷（3 维） | 评论情感分析 ＋ 问卷校准 | B | 非同源情感证据 |
| PI | 问卷（3 题） | 个体：问卷＋行为校准；或品牌层用销量 | A / B | 意愿—行为 gap 显性化 |

## 2. 九条假设在新设计下的数据来源

| 假设 | 原数据 | 新设计数据 |
|---|---|---|
| H1 / H7（GCS 路径） | 同源问卷 | 客观 GCS（编码/实验）→ 问卷 SBC/PI |
| H2 / H4（CI 路径） | 同源问卷 | 问卷 CI（可保留） |
| H3（SBC→PI） | 同源问卷 | 问卷 SBC；PI 可问卷或行为 |
| H5（PV→PI） | 同源问卷 | 客观 PV 维度 ＋ 问卷 |
| H6（BA→PI） | 同源问卷 | 文本 BA ＋ 问卷校准 |
| H8 / H9（中介） | 同源问卷 | 前因非同源化后重估中介，Bootstrap 检验 |

> 非同源化使关键前因（GCS、PV、BA）与结果不再来自同一量表，中介估计的方法偏差显著降低。

## 3. CMV 前后对比

| 维度 | 原设计 | 混合设计 |
|---|---|---|
| 数据来源 | 全部同一问卷 | 客观编码 / 文本 / 行为 / 问卷多源 |
| 采集时点 | 同一时点 | 刺激/文本/行为可在不同时点采集 |
| 评分者 | 全部被试自评 | 部分由研究者/模型客观评定 |
| CMV 风险 | 高 | 中/低（仍需统计检验确认） |

## 4. 两条路径取舍

- **路径 A（推荐）**：保留个体 PLS-SEM。GCS、PV 客观化，CI/SBC 留问卷，BA/PI 引入文本与行为做校准和 CMV 校正。问卷精简但不消除，理论模型完整。
- **路径 B**：改品牌/SKU 层面，GCS/PV/BA/PI 几乎全客观替代，可跑品牌层模型；代价是放弃或聚合化 CI、SBC 个体身份构念。
- 选择依据：若核心理论贡献在"身份→连接→意愿"的个体机制，选 A；若目标是预测品牌/产品层面的市场表现，选 B。
