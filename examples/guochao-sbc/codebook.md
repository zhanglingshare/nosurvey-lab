# GCS 客观编码本（Codebook v1）

> 目的：把 S-O-R 中的"国潮文化刺激（GCS）"从消费者感知题，还原为**可客观观测、可复现的产品视觉特征**。分析单位：单件服饰 SKU 主图。

## 评分维度（0–3 分制）

通用尺度：0＝无/不可见，1＝弱/局部，2＝中/明显，3＝强/主导。

| 代号 | 维度 | 判定要点 |
|---|---|---|
| M | 传统纹样/符号 | 龙凤、麒麟、仙鹤、牡丹、青花、祥云、山水、蝴蝶、民族图腾、生肖、书法汉字、印章等 |
| C | 传统工艺呈现 | 刺绣、织金/妆花、盘扣、提花、手绘水墨、传统印染等在图中的可见度 |
| S | 传统版型/结构 | 立领、盘扣门襟、交领右衽、飞机袖、马面褶、唐装/汉服剪裁 |
| R | 美学重构/当代表达 | 传统元素与现代版型（T 恤/卫衣/oversize/街头）融合再设计的程度 |
| D | 元素密度/覆盖 | 国潮元素的覆盖面积：局部点缀 ↔ 满印/重工 |

## 客观分类标记（不计入总分）

- 品类：T 恤 / 卫衣 / 裙装 / 外套 / 裤装
- 主元素：人物 / 神兽动物（龙凤麒麟鹤鱼）/ 花卉 / 几何图腾 / 器物乐器 / 文字 / 山水
- 主色调：红 / 蓝 / 黑 / 白 / 粉 / 紫 / 杂
- 是否满印：是 / 否
- 是否可见 IP/联名：是 / 否 / 不可判断

## 合成指标

- **GCS 总分** ＝ M＋C＋S＋R＋D（0–15）
- **GCS 指数** ＝ 总分 / 15（0–1）
- 强度分级：0–3 弱 ｜ 4–7 中 ｜ 8–11 强 ｜ 12–15 极强

## 信度规则

1. 编码者依据本编码本独立打分，不参考商品标题与价格，仅依据图像。
2. 正式研究需两名编码者独立编码，报告各维度一致率、总分相关/ICC；不一致项协商。
3. 本案例先由编码者 A 完成，并提供双人信度脚本；**双人信度待第二编码者补充**，不得用重测替代独立第二人。

## 边界

- 编码只反映"图像可见的客观特征"，不等同消费者主观感知；感知题可保留为操作检查。
- 商品图仅用于学术编码分析，不公开发分发原图；来源见 `sources.md`。
