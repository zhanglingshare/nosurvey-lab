# 案例 · 国潮服饰购买意愿（S-O-R / SBC 模型）

> 案例类型：**设计阶段问卷替代诊断**（非事后论文复现）。在研究尚未发放问卷前介入，判断每个构念能否用公开数据/数字痕迹替代，并提升效度。

## 研究问题

国潮文化刺激（GCS）、文化认同（CI）、感知价值（PV）、品牌情感（BA）如何经由自我—品牌连接（SBC）影响 00 后大学生的国潮服饰购买意愿（PI）。

- 理论框架：S-O-R（刺激—机体—反应）＋ 社会认同理论 ＋ 自我一致性理论
- 分析方法：PLS-SEM
- 目标样本：广州高校 00 后在校大学生
- 构念数：6 ｜ 假设数：9（H1–H7 直接效应，H8–H9 部分中介）

## 诊断结论速览

1. **无法零问卷**：与"区域经济"案例（75% 可全网替代）相反，本研究以个体深层心理构念为主，CI、SBC 即问卷应在的位置。
2. **最大杠杆：GCS 客观化**。它在 S-O-R 中是"刺激（S）"，本质是可客观编码/操纵的产品特征，不应只作为感知题测量；客观化同时增强因果识别。
3. **隐藏收益：缓解共同方法偏差（CMV）**。原设计 6 构念同源、同时、同被试，CMV 风险高；引入客观 GCS、文本 BA、行为 PI 等非同源数据可从根本上回应。

## SRG 分级分布

| 构念 | 角色 | SRG（终审） |
|---|---|---|
| GCS 国潮文化刺激 | S（刺激）/ IV | **A（可 S）** |
| CI 文化认同 | IV | **C** |
| SBC 自我—品牌连接 | 中介 | **C** |
| PV 感知价值 | 直接前因 | **B**（价格/参数维度 S） |
| BA 品牌情感 | 直接前因 | **B** |
| PI 购买意愿 | DV | **A（品牌层）/ B（个体层）** |

**推荐路径**：路径 A——混合设计（GCS、PV 客观化；CI/SBC 保留问卷；数字痕迹做效度锚点与 CMV 校正）。
