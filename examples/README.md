# 案例库 · Examples

> 定位：Nosurvey Lab 的信任状与护城河。空框架谁都能复制，**"已经跑通、可核对的真实案例"复制不走**。每个案例都应能让研究者照着复现。

## 门面案例：论文复现（Replication Demo）

最有说服力的入口：选一篇**已发表的问卷论文**，用公开数据/数字痕迹替代其问卷，重跑核心模型，做结论对照。

选择标准：

1. 高频被引、框架典型（如动态能力 / TAM / 资源基础观）；
2. 核心构念 80% 以上为 SRG-S/A/B，替代后模型仍可跑；
3. 样本为上市公司或规上企业，公开数据可一一对应；
4. 原文结论清晰，便于做"问卷结论 vs 替代数据结论"对照——一致证明可行，**不一致更有价值**（展示代理看到了问卷看不到的东西），但必须解释差异来源。

## 单个案例目录结构

```
examples/<案例短名>/
├── README.md            # 案例总览：原论文引用、研究问题、结论速览
├── constructs.md        # 构念清单 + SRG 分级（含评定依据、双人评定记录）
├── data-sources.md      # 替代数据源、取数方式、时间窗、口径
├── replication.md       # 核心模型复现过程 + 问卷/替代结论对照表
├── validity.md          # 效度与稳健性（校准/文献/三角）
└── assets/              # 可公开的代码、脱敏图表（不含付费数据本体）
```

## 贡献规范（合规红线）

- **必须脱敏**：不得含可识别个人信息；企业/客户敏感数据须聚合或匿名。
- **数据合法**：贡献者保证所用数据合法、有权公开；付费数据库（Wind/企查查 VIP/incoPat/研报）**只讲方法与结论，不提供数据本体**。
- **受限平台**：微博/小红书/抖音/知乎不提供具体爬虫或绕过代码，只给合规原则与合法替代语料。
- **可复现**：优先公开取数代码与计算口径，让他人能核对。
- **署名**：保留原论文与复现者引用；案例采用 CC-BY，代码采用 MIT。

## 验收

案例入库前检查：构念是否标注 SRG 等级、效度证据是否齐备、是否完成脱敏、结论对照是否清晰、是否含违规采集内容。
