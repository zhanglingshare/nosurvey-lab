# 数据源地图 · 国内外双轨

按替代通道 + 优先级分组。每个源标注访问方式与已知坑。
使用规则：先国内可及源，再国外成熟参照；拿不准的源标注"需核实"。

---

## 一、国外开放 API（文本/网络替代主力）

| 数据源 | 通道 | 可测构念 | 访问方式 | 已知坑 |
|---|---|---|---|---|
| X/Twitter API | 文本/网络 | 情绪、态度、影响力网络 | 开发者API（付费分层） | 免费额度小；需学术接口申请 |
| Reddit API | 文本/网络 | 态度、职场/消费讨论 | 公开API | 需遵守使用条款；子版块偏差 |
| SEC EDGAR | 文本 | 管理层语调、风险披露 | 免费公开 | 仅英文；需解析10-K/10-Q |
| OpenAlex | 网络/文本 | 学术合著网、引文、学科演化 | 免费API | 覆盖面偏英文期刊 |
| GDELT | 文本 | 全球事件、新闻情感、注意力 | 免费（大数据量） | 数据量极大需分布式处理 |
| Google Trends | 痕迹 | 搜索行为、公众关注度 | 免费 | 相对值非绝对值；采样波动 |

| 数据源 | 可测构念 | 访问方式 | 已知坑 |
|---|---|---|---|
| ACS（美国社区调查） | 收入/就业/住房/人口 | 免费下载 | 美国样本，跨文化需谨慎 |
| PSID（收入动态面板） | 收入动态、代际流动 | 申请制 | 需注册审批 |

| UK Biobank | 健康/基因/生活方式 | 项目审查制 | 门槛高 |
| World Bank WDI | 宏观面板 | 免费API | 口径需对齐年份 |
| OECD Stats / IMF IFS / UN Comtrade | 宏观/贸易 | 免费 | 各国口径不一 |

| 数据源 | 通道 | 可测构念 | 访问方式 | 已知坑 |
|---|---|---|---|---|
| 巨潮资讯/上交所/深交所 | 文本 | 管理层语调、战略披露 | 免费公开 | PDF解析成本高 |
| 中国裁判文书网 | 文本 | 纠纷类型、司法行为 | 公开（有访问限制） | 批量抓取受限，需合规评估 |
| CNIPA / incoPat 专利数据 | 网络/文本 | 技术创新、知识网络 | 公开检索/付费 | 清洗工作量大 |

| CGSS / CFPS / CLDS / CHFS | 事实 | 收入/健康/家庭资产 | 申请制 | 需注册审批，滞后1-2年 |
| 企查查 / 天眼查 | 事实/网络 | 企业进入退出、股权链 | 付费API/网页 | 免费额度少；爬取需合规 |
